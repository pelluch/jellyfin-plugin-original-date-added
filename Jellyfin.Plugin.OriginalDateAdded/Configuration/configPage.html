Jellyfin is set to "Use file creation date" as the date added for new content. This plugin is designed for "Use date scanned into the library": with the file creation date, a file replaced under the same name gets a new date added that this plugin doesn't restore. Change it in Libraries → Display, "Date added behavior for new content".
Maximum number of days that can pass between an item being removed and its replacement being scanned in before it is no longer eligible for an added date update. Beyond this, the item's replacement will get added to "Recently Added" as per the logic without this plugin. Set to 0 for no limit.
Dates added that differ by less than this are left as they are: rounding between sources, and Jellyfin scanning a file a few minutes after Sonarr or Radarr imported it.
How many of the most recently added movies and episodes the "Restore original dates added" task checks. Set to 0 to check all of them.
Log what would change without changing any date added. Removed items are still recorded in the plugin's internal data, but no Jellyfin metadata changes occur.
Increases log verbosity.

Sonarr / Radarr

When enabled, movies and episodes managed by Sonarr or Radarr get their date added from Sonarr's and Radarr's import history. Files are matched by path: If the Jellyfin and arr paths don't match, add path mappings.

Tracearr

When enabled, item added dates will also be looked up from Tracearr's history
Tracearr public API token (trr_pub_…).
The Tracearr server must be this Jellyfin. if your Tracearr instance has multiple, verify the name is correct.

Jellystat

When enabled, item added dates will also be looked up from Jellystat's history. Jellystat has no provider IDs, so movies and shows are also matched by name and year. It doesn't record when a copy was removed, so the replacement window doesn't apply to its dates: a movie deleted and downloaded again much later gets its old date back.
Jellystat API key (Settings → API Keys in Jellystat).

Data

Forgets every date this plugin set and every removed item it recorded. Dates added in Jellyfin stay as they are, but can no longer be reverted to their scanned dates. A backup is saved next to the data first; the last 5 are kept.
